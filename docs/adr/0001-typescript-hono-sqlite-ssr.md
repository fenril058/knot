# 0001: TypeScript + Hono + SQLite の単一プロセスで作る

- 状態: 承認済み（閲覧画面と編集画面の分離は ADR 0006 により置換）
- 決定日: 2026-07-10（記録日: 2026-08-02）

閲覧はサーバサイドレンダリングとし、編集画面だけ CodeMirror を載せる。
サーバは Hono、ストレージは SQLite を使い、TypeScript で動く単一プロセスとして構成する。

Cosense 記法の既存パーサを利用でき、サーバとエディタを単一言語で書けることを TypeScript 採用の決め手とした。
ストレージ層には交換可能な境界を設け、将来 Cloudflare Workers + D1 へ移す余地を残す。

## 却下した案

**Go の単一バイナリとして作る案**。
配布は単純になるが、Cosense 記法のパーサを自作する必要があり、互換性の難所を最初から自前で背負う。
Workers への移行路も狭くなるため採用しない。

## 帰結

- SQLite とパスワードハッシュには Node.js のランタイム内蔵機能を使い、ネイティブ依存のビルドを避ける。
- Cosense 記法の外部パーサには、保守が止まる可能性を受け入れ、バージョン固定と回帰テストで備える。
- Workers + D1 への移行では、ストレージの差し替えだけでなく、Node.js 固有のファイル I/O と複数ページの原子的更新も作り直す。
