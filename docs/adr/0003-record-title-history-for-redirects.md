# 0003: 旧タイトルからのリダイレクトに備えてタイトル履歴を記録する

- 状態: 承認済み
- 決定日: 2026-07-10（記録日: 2026-08-02）

旧タイトルから現在のページへリダイレクトできるよう、タイトルが変わるたびに旧タイトルと有効期間を記録する。
v1 ではリダイレクトを提供しないが、後から過去の利用実績を復元できないため、履歴の記録だけを先に始める。

## 却下した案

**リダイレクトを実装するときにコミット履歴を毎回再生する案**。
過去タイトルは復元できるが、存在しないタイトルへのアクセスごとにページの全履歴を再生することになるため採用しない。

**記録したすべての旧タイトルを無条件にリダイレクトする案**。
逐次保存の途中に現れる一時的なタイトルまで恒久的な入口になるため採用しない。

## 帰結

- リダイレクト対象は、タイトルの存続時間で絞る方式を第一候補とする。
- 精度が足りなければ、実際に閲覧されたタイトルだけを使う方式を検討する。
- 閲覧実績を使う場合は、最後の閲覧だけでなく履歴を保持できるデータモデルが必要になる。
