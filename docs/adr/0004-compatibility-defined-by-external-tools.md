# 0004: Cosense 互換性を、動作保証する外部ツールで定義する

- 状態: 承認済み
- 決定日: 2026-07-17（記録日: 2026-08-02）

「Cosense 互換」を公開仕様への準拠としてではなく、knot 上での動作を保証する外部ツールとバージョンの集合として定義する。
Cosense の API に公開仕様がなく、完全な準拠先を定められないためである。

現在の対象は `scrapbox-cosense-mcp` と `@helpfeel/cosense-cli` であり、保証するバージョンは lockfile と受け入れテストで固定する。

## 却下した案

**Cosense の観察可能な API 応答を網羅的に複製する案**。
対象とする仕様の境界がなく、利用されないフィールドまで推測で実装することになるため採用しない。

## 帰結

- 外部ツールが実際に使う API とフィールドだけを互換契約とする。
- 対象ツールを増やす場合は、受け入れテストを追加し、新しい ADR でこの決定を supersede する。
- 対象ツールの更新で必要な API または保証範囲が変わる場合も、互換性の定義変更として新しい ADR を書く。
