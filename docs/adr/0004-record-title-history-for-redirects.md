# 0004: 旧タイトルからのリダイレクトのために title_history を今から記録する

- 状態: 承認済み
- 決定日: 2026-07-10（記録日: 2026-08-02）

`title_history` は v1 では書くだけで、読む UI を持たない。
それでも最初から記録するのは、後から足すと、それ以前の期間についてリダイレクトを提供できないからである。

未使用に見えても消してはならない。
消した時点より前のタイトル変更は復元できない。

なお `page_visits` は v1 でも読んでいる（テロメアの未読判定）。
将来この判定を旧タイトルの絞り込みにも再利用できるという副次的な事情はあるが、`page_visits` 自体は将来のために置いているテーブルではない。

## なぜ素朴な履歴引きでは足りないか

タイトル行の編集は逐次保存される。
そのため「カレー」を「curry」へ変える途中の「カレ」「カ」「c」「cu」といった一時タイトルが履歴に残り、「カ」へのアクセスが curry へ転送されてしまう。
Cosense がアクセス履歴方式を採っているのはこの理由による。

`title_history` は有効期間（`started`、`ended`）を持つので、「一定時間以上そのページのタイトルであり続けたタイトル」だけを対象にする方針を第一候補とする。
編集途中の一時タイトルは数秒しか存続しないため、この条件で外れる。

精度が足りなければ、Cosense と同じアクセス履歴方式へ切り替えられる。
テロメアのために記録している `page_visits` と `title_history` を突き合わせれば、「そのタイトルであった期間に実際に閲覧されたことのあるタイトル」だけを対象にできる。

どちらの方式でも、差し込み点は v1 の 404 ハンドラ（新規作成を促す画面）ひとつである。
