# 0005: v1 はログイン利用者だけが全プロジェクトを読み書きする

- 状態: 承認済み
- 決定日: 2026-07-10（記録日: 2026-08-02）

v1 はログイン必須のクローズドな wiki とし、ログインした利用者はすべてのプロジェクトを読み書きできる。
公開閲覧とプロジェクト単位の権限は、必要になった時点で認可モデルと脅威モデルを一緒に設計する。

ブラウザの書き込みはセッション cookie とカスタムヘッダの両方を要求する。
SameSite cookie と、クロスオリジンの単純なフォーム送信では付けられないヘッダを組み合わせて CSRF を防ぐ。

## 却下した案

**v1 から公開閲覧またはプロジェクト単位の権限を持たせる案**。
認可規則と、信頼できない利用者を前提にしたリソース制御を同時に設計する必要があり、2〜5 人で使う初期要件には過剰である。

**SameSite cookie だけを CSRF 境界にする案**。
ブラウザや周辺ツールからの書き込み経路を明示的に識別できないため、カスタムヘッダも要求する。

## 帰結

- 公開閲覧を追加する際は、認可だけでなくアップロード、レート制限、リソース消費の前提も再評価する。
- ブラウザ以外の互換ツールには personal access token による API 認証を提供する。
- 継続的に守る安全要件は `docs/security.md` に記録する。
