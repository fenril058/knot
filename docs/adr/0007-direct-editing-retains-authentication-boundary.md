# 0007: 直接編集でもログイン必須の境界を維持する

- 状態: 承認済み
- 決定日: 2026-08-09
- 置換対象: ADR 0006 のうち、未ログイン時も本文を閲覧可能にする決定

正規 URL での直接編集を導入しても、ADR 0005 のログイン必須の境界を維持する。
未ログインで正規 URL を開いた場合は本文を返さず、`next` に正規 URL を指定したログイン画面へリダイレクトする。
JavaScript が動かない場合も本文を閲覧可能にする要件は、ログイン済み利用者に適用する。

## 却下した案

**直接編集と同時に未ログイン利用者へ本文を公開する案**。
公開閲覧には認可規則だけでなく、アップロード、レート制限、リソース消費を含む脅威モデルの再設計が必要であり、直接編集とは別の決定として扱うため採用しない。

## 帰結

- 正規 URL の既存ページと新規ページ候補は、どちらも現在の HTML 認証を通す。
- 未ログイン時の回帰テストは本文の表示ではなく、`next` 付きログイン画面へのリダイレクトを確認する。
- JavaScript 無効時の回帰テストは、ログイン済み利用者が意味の通るサーバサイドレンダリング済み文書を閲覧できることを確認する。
- 公開閲覧を導入する場合は、ADR 0005 とこの ADR を置き換える新しい決定を記録する。
